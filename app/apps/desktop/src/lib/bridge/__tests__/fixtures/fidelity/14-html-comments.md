# HTML comments

An inline comment: <!-- hidden note --> visible text.

A multi-line comment:
<!--
line one
line two
-->

A comment with markdown inside:
<!-- **not bold**, [[not a link]] -->

Obsidian-style comments: %%this is hidden%% and inline.

%%
A block obsidian comment.
Multiple lines.
%%

A raw HTML block:

<div class="note">
  <p>Some <strong>inline</strong> HTML inside a block.</p>
</div>

A details block:

<details>
<summary>Expandable</summary>
Content inside.
</details>
